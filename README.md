# ~~~Planejador de viagens~~~ #

# ~~~Descrição~~~ #
Um programa que auxilia no planejamentos de viagens, 
apresentando funções basicas necessárias para se preparar para as mesmas.

# ~~~Funcionalidades~~~ #
Apresenta um menu principal que possibilita a escolha entre
4 funções principais

- Cálcular o custo do combústivel;
- Cálcular o tempo da viagem;
- Dividir as despesas entre as pessoas;
(obs: Anões não permitidos! Nem gnomos, não adianta insistir!)
- Realizar a conversão entre reais e dólares;

# ~~~Comandos~~~ #

- npm install
- node planejador.js
